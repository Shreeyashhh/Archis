Supabase PostgreSQL & Auth Credentials
Checking...

Connect your official Supabase PostgreSQL database to enable live data persistence, Row Level Security (RLS), and secure admin logins.

Found in: Supabase Dashboard → Project Settings → API → Project URL
Never use the secret service_role key here. Only provide the public 'anon' key.
Initial Database Setup:
  1. Create a free project at supabase.com.
  2. Go to SQL Editor in Supabase and paste the contents of supabase-schema.sql.
  3. Go to Authentication → Users and click Add User (e.g. owner@pcmcwashingcentre.com).
  4. Authorize the user in SQL editor: SELECT public.register_initial_admin('owner@pcmcwashingcentre.com', 'Owner');
